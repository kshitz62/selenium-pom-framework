# Selenium POM Automation Framework

A test automation framework built with Selenium WebDriver, Java, and TestNG, using the Page Object Model (POM) design pattern.

## Features
- Page Object Model architecture (LoginPage, InventoryPage)
- Data-driven testing using CSV file input
- Explicit and implicit waits for reliable element handling
- XPath and ID-based locator strategies
- Automated login flow testing on saucedemo.com

## Tech Stack
- Java
- Selenium WebDriver 4.46.0
- TestNG
- Maven
- CSV-based data-driven testing
